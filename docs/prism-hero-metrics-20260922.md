# 主视觉用量信息与贴边修复 · 2026-09-22

## 结果

本机 0.11.0 (9) 已安装，保留原 Developer ID 与应用身份。正式监控台已通过视觉和交互验收。未发布公网安装包或自动更新。

主视觉将装饰大字替换为当前筛选范围的真实 Token 总量、调用次数、输入、输出、缓存写、缓存读。读取已有 UsageAggregator 输出，不新增扫描或重新计算一套口径。加载时显示横线；总量明确包含四类 Token。日期、工具、项目、模型和 Token 构成筛选继续作用于同一份 dashboard.overview 数据。下方保留费用估算、额度、消耗速度、复用率和数据质量提示。

## 边缘根因与改动

此前主视觉放在统一 padding(20) 的内容容器中，机械前景被内部舞台提前截断；背景圆角进一步造成右端缺角。现在主视觉单独通栏，只有下方数据卡片保留 20pt 阅读边距；背景横带取消内侧圆角，机械图在实际窗口边界裁切。上下破框有真实布局占位。

Prism 工具栏明确撑满窗口，使用不透明主题底色；分隔线改为全宽连续线，去掉只绘制一小段亮线的装饰。其他主题保留原样式。

菜单栏面板同步去掉主视觉外侧水平内边距，并去掉贴边背景卡片的内侧圆角；其系统状态内容仍保留阅读边距。该弹窗组件渲染已检查，正式弹窗的现场截图验收仍未完成，不与监控台验收混为一谈。

## 防退回

1. 主视觉不得再次包进数据卡片的水平 padding；背景、图像裁切终点均以窗口内容边缘为准。
2. Prism 工具栏的背景和分隔线必须在撑满宽度之后绘制，不能只画局部亮段冒充连续边线。
3. 主视觉只消费当前筛选的 dashboard.overview；不能改用固定 today 汇总，避免切日期或筛选后主视觉与卡片不一致。
4. 正式入口分别验收窄/常规窗口、加载/有数据、日期切换、Token 构成筛选和一键恢复。原生组件图不能替代现场窗口截图。
