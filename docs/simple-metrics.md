# 免费统计与迁移约定

下载使用 GitHub Release asset 的 `download_count`。运行 `scripts/查看下载统计.command` 获取实时快照，输出保存在被 Git 忽略的 `dist/metrics/`，包括 HTML、JSON、CSV 和历史快照。统计只包含公开安装 DMG；TokenMini 和旧名 MacPulse 分开，校验文件、源码压缩包和调试符号不计入。下载次数无法推导人数或安装数。

0.14.0 保留默认关闭、需明确同意的匿名产品统计客户端。正式接收服务尚未配置时，设置中禁用开关并说明原因，不发送统计，也不把缺失的日活/周活标为零。GitHub 不提供应用日活/周活；不要把仓库访问量当成应用活跃量。

免费服务接入目标为 Cloudflare Workers + D1；启用需要运营者登录并确认免费套餐，不创建收费资源。接入前必须验证真实客户端 → HTTPS 接收 → 持久化 → 私有报表完整链路，再配置正式包。客户端只带公开写入标识，读取密钥只放服务端。免费额度用尽时统计暂停，不自动升级收费，不影响应用本地功能。

## 稳定口径

- 日活：北京时间当天启动应用或实际与面板交互的、自愿参与统计的随机设备标识去重数。
- 周活：含当天的最近 7 个北京时间自然日中，上述标识去重数；不能相加每日人数。
- 后台驻留时长独立于前台交互时长，不能仅因后台计时就算作活跃。
- 设备标识不是账号或自然人。卸载重装、关闭后重新同意可能产生新标识；不能推导总安装人数。
- 测试与生产、不同产品必须隔离；健康状态必须区分未接入、无样本、接收失败和真实的零。

## 可迁移接口

客户端事件固定白名单，不允许自定义自由文本：产品、平台、版本、随机标识、事件 ID、原始时间、启用来源、运行/交互时长。禁止聊天、提示词、文件名/路径、项目、账号、Token 明细、密钥和设备指纹。接收方必须拒绝多余字段、限制体积/请求频率、按事件 ID 去重，并保留原始时间处理离线重传。

日活服务只需保存有期限的去重设备日记录和聚合数；接入时明确保留期及删除方式。SQL/CSV/JSON 导出使用 `schema_version`, `product`, `environment`, `day`, `metric`, `value`, `observed_at`。采集协议与报表适配器分离，未来可以接 OpenPanel 或自建服务，不需要替换应用业务层。

公开仓库只保留代码、数据结构与使用说明。数据库、匿名标识明细、生产报表、管理员凭据与本机测试截图全部私存。不要把 GitHub Issues、公开仓库提交或 Actions 日志用作用户事件数据库。
