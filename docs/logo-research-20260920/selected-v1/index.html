这次规范了什么

几何统一

斜边统一 25°，竖边垂直。水平间隔 16u，右下端点共用一条基线；圆角随片宽按同一比例变化。

文字固定

保留轻量、方圆几何的字形气质，重新绘制轮廓并固定字距。SVG 不依赖安装字体。

干净、可缩放

去掉光晕和生成纹理，使用实色。16–24px 单独加宽最小片和间隙，保留四片结构。

u 是母版的相对尺寸单位，不是像素。净空建议至少 32u；横向完整 Logo 建议宽度不小于 180 CSS px。
