## 本次修正

1. **统一四片几何。** 所有斜边 25°、竖边垂直，四片顺序固定；宽度 88 / 53 / 32 / 21u，高度 160 / 128 / 64 / 26u。u 是此母版的相对尺寸单位，不是屏幕像素。
2. **固定排列关系。** 水平间隔统一 16u；四片右下端点共用基线。圆角按各片宽度的 6% 计算，以圆弧与直边相切，避免小片被过大圆角吞掉。
3. **规范文字。** 依照所选原稿的轻量、方圆几何风格重绘 TokenMini 字形，固定大小写、笔画与字距；所有文字保存为路径轮廓。图形到字标间隔固定 40u，组合后不可单独拉伸其中一项。
4. **规范颜色。** 标准墨色 `#18211C`、绿色 `#68B45B`、白色 `#FFFFFF`；浅色展示底 `#F5F6EF`。绿色版只给第二片上色，位置固定；不是实时余额或占比指示。
5. **取消非必要效果。** 标准文件不含发光、投影、描边、纹理和半透明实体。PNG 边缘保留正常抗锯齿；图形内部为实色。
6. **单独处理小尺寸。** 16–24px 的光学校正版适度加宽最小片和间隙，保留四片结构。每个尺寸提供 1× / 2× / 3× PNG。它们用于小尺寸，不应用于大幅放大；大尺寸使用标准母版。

## 使用规则

- 保留四片的数量、顺序与倾角。不可镜像、旋转、挤压、把所有片改成等宽，也不可变成实时涨跌柱。
- 大尺寸横向 Logo 的图形高度约为字标大写高度的 1.8 倍，已在母版固定。不得重新用系统字体打出名称替换字标。
- 推荐外围净空至少 32u（标准母版中最大片宽度的约 0.36 倍）。SVG 的画布留白不一定覆盖所有场景所需的外围净空，排版时仍需给相邻内容留空。
- 横向完整 Logo 建议不小于 180 CSS px 宽；独立标志建议不小于 16 CSS px。16 / 20 / 22 / 24px 选对应光学校正版，32px 及以上用标准版。
- 浅色背景用墨色，深色背景用白色；绿色仅作为品牌点缀。照片或复杂底纹上，先增加简洁底板与留白。
- 标准版应静止显示。余额、购买按钮、实时状态应由界面明确标注，不依赖 Logo 的绿色片传达。
- 颜色按屏幕 RGB 交付；实体印刷应由印刷方依据纸张和工艺打样，不把屏幕颜色当作印刷色样。

## 业务含义

品牌范围按用户确认的“Token 监控 + Token 售卖”处理。四片可表达 Token 用量单元与清晰的计量节奏；对外可用“Token 购买与用量管理”解释业务。图形本身不承担功能说明、余额指示或费用准确性证明。

## 范围与验收

本次交付规范化品牌文件与本地查看页，没有替换现有 App、官网或已安装应用的资产。小尺寸验收是本地展示页和导出图的视觉检查，不等于已安装 macOS 菜单栏、Dock、Finder 验收。

`verification.json` 记录本轮结构检查、导出检查和浏览器检查。`specification.json` 保存几何、颜色和选定来源。`edit-prompt.md` 保存内置 imagegen 的清理提示词。

## 重建

```sh
DYLD_FALLBACK_LIBRARY_PATH=/opt/homebrew/lib python3 build_assets.py
```

依赖 Python 与 CairoSVG；此命令仅重建本目录规范资产，不修改产品代码或安装应用。
