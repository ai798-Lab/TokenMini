2026-09-20。用户在第二轮参考研究后授权开始设计。

## 查看

- 对照入口：`index.html`，支持筛选和放大；所有原图在浅色底展示。
- 单张浅底入口：`preview.html?id=01`、`preview.html?id=02`、`preview.html?id=03`。
- 01：`01-wordmark.png`，字标主导。
- 02：`02-spatial.png`，非圆形空间截面及银绿材质研究。
- 03：`03-sampling-grid.png`，四块离散形体的采样栅格。
- `03-sampling.png` 为未采用的初稿，造型过于接近常见信号柱，只作过程记录。

内置 imagegen 共生成 4 张，交付 3 个候选。完整提示词见 `prompts.md` 与 `prompt-03-revision.md`。未输入外部参考原图或私人聊天。

## 当前设计判断

02 的单色轮廓与空间形体值得优先讨论，但它的形状可能让人联想到字母 S，且材质与平面版本仍需统一。01 字标具有可读性与连续节奏，辅助符号看起来像独立的叶片 / F，与名称的联系还不充分。03 的模块区别明确，但整体更像一组符号单元，小尺寸完整性需要后续实测。三者均为候选，不代表用户已选定，也没有进行商标检索。

## 已检查与边界

已逐张在 Chrome 的浅色底入口目视检查：TokenMini 拼写、主图显示和各方案轮廓。四份 PNG 均可完整解码，1536 × 1024，RGBA。
