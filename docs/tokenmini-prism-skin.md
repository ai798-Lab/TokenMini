# TokenMini · Prism 官网同款皮肤

主视觉直接复用官网的透明机械圆环与绿色光束原图。应用中保持静态，不加载逐帧序列，不新增持续三维渲染。

## 统一规范

| 元素 | 规范 |
| --- | --- |
| 背景 / 正文 | 墨黑 #0B0D0C，暖白 #F1F1E9 |
| 品牌与选中态 | 荧光绿 #B5FF39；实色选中态用深色文字 |
| 面板 | 深色底、1 pt 结构线、6 pt 圆角、短荧光标线 |
| 按钮 / 筛选 / 标签 | 4 pt 圆角；主要控件最小 28 pt 高，悬停、按下、禁用状态同源 |
| 排版 | 主要读数粗体与等宽数字；36 pt 数值区、100 pt 最小内容区统一指标卡基线与高度；正文使用系统无衬线字体 |
| 图表 | 主绿、暖白、冷银与少量辅助色，图例和图形统一取色；保留明确系列名称 |
| 语义状态 | 警告保持黄、错误与高负荷保持红；不把所有状态都染成品牌绿 |

入口沿用“外观 → 主题 → Prism 光核 · 官网同款”。原经典、HUD、LED 主题与已保存偏好保留；选择 Prism 时，监控台、菜单面板、共享数据卡片、主要筛选器及辅助窗口一起切换。

## 实现范围

- 顶部浅色大字与机械图跨区构图，下方保留真实数据状态和分析内容。
- 分段选择、菜单外框、按钮、状态标签、进度条和图表图例通过共享组件统一。
- 菜单底框绘制在 Menu 外层，避免 macOS 忽略菜单 label 背景。
- 保留来源、更新时刻、未知模型、API 等价费用解释、隐私模式和重置筛选。
- 只有直接交互的短过渡；系统“减少动态效果”关闭这些过渡。原生系统确认弹窗保留其可访问性与危险操作语义。

## 验证边界

本次为本机 0.11.0 (6) 验收构建。使用现有 Developer ID 签名，正式应用与构建输出逐文件一致。现有测试 34 项通过、2 项依赖显式环境启用而跳过。

已在 `/Applications/TokenMini.app` 实际检查主视觉、真实数据自动载入、工具筛选及重置、图表的模型与成本构成切换、总览与分析模式、Prism 与 HUD 主题往返切换，并检查约 800 × 730 和 1080 × 730 的窗口。最终恢复为 Prism、今日、分析模式、无额外筛选。

菜单面板与辅助页面已接入共享皮肤；全部辅助窗口、菜单栏弹出面板、VoiceOver 及不同显示器环境尚未逐项验收。主视觉为静态，控件反馈为短过渡。

详细的本机安装与实际界面验收记录保留在本地维护资料中。此皮肤没有作为新的 GitHub Release 或自动更新版本公开发布。
