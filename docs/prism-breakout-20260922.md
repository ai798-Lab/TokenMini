# Prism 上下破框 · 2026-09-22

## 已实现的同步范围

菜单栏弹出面板与完整监控台的主视觉一起调整，使用官网同一张透明机械圆环素材，以及共享的 PrismBreakoutArtwork 原生组件。

- 背景卡片单独裁圆角，机械前景不受卡片矩形裁切。
- 监控台：机械图跨过浅色品牌区、深色说明区与底部绿条，上下均伸出卡片；按可用宽度等比例构图。
- 菜单面板：178pt 舞台中放置 122pt 背景卡片，前景上下突出；标题使用暖白底，读数保持深底浅字。左侧为 130pt 数字区，右侧光束至少让出 8pt。
- 外层布局为破框部分预留真实占位；装饰不响应点击，不覆盖前后功能区。
- 机械图继续静态展示，不添加持续动画。

版本 0.11.0 (8)，已安装到正式 TokenMini.app。与构建输出的 98 个文件内容清单一致，使用原 Developer ID，严格递归签名验证通过。原 build 7 已备份。未公开发布新安装包。
