# TokenMini 多工具与模型接入

实现日期：2026-09-22。此版本仅本机更新，没有公开发布。

## 开源方案与取舍

- [ccusage](https://github.com/ccusage/ccusage)，MIT：复用 Kimi 新旧 wire 格式、turn 范围计数和多路径去重规则；将 models.dev 离线价格快照转为本机参考目录。
- [TokenTracker](https://github.com/xiufengsun/TokenTracker)，MIT：移植 Cursor CSV 缓存字段归一化、Trae Work CN 官方会话接口、分页完整性校验、tc-v5 登录状态兼容逻辑和公开合成测试样例。
- [CodexBar](https://github.com/steipete/CodexBar)，MIT：考察了其 macOS 多数据源组织方式。此次不捆绑整个应用，避免增加第二套菜单栏和账号状态管理。

原项目版本、源码位置和许可证见 Resources/ThirdParty/NOTICE.md；许可证随 app 分发。只移植适合现有 Swift 管线的部分，没有运行上游安装脚本、上传服务或 hooks。

## 用户入口

打开 TokenMini → AI 用量监控台 → 数据源。

| 工具 | 当前接入方式 | 范围 |
|---|---|---|
| Claude Code、Codex | 本地会话自动扫描 | 60 秒自动更新 |
| Kimi Code | 本地 wire.jsonl，新旧目录去重 | 60 秒自动更新；缺少模型标识时不猜价格 |
| Gemini CLI | 本地 session JSON | 60 秒自动更新 |
| OpenCode | 本地 SQLite，只读 | 60 秒自动更新 |
| Cursor | 官方 CSV 导入 | 手动导入，重复记录去重 |
| Trae Work CN | 可选的官方只读查询 | 点击同步近 30 天，保存会话汇总；不是后台持续同步 |
| Trae 国际版、Windsurf、Copilot、Cline、Roo Code、Kilo Code、Qoder、WorkBuddy、Antigravity、其他 | 通用 CSV / JSON / JSONL 导入 | 需按模板转换；不是自动抓取这些工具账号 |

不同工具的文件导入使用同一统计、筛选和图表管线。模板仅含时间、模型、Token、可选费用、项目和会话；不收录聊天正文。

## 模型和价格的真实含义

- 模型名字没有白名单限制：任何模型都能统计 Token。
- 先应用自定义价格，其次内置核实价格，最后社区目录的完整模型 ID 精确匹配。
- 开源目录保留 2,595 条平价记录（含渠道与版本，非 2,595 个独立基础模型），未适配的 254 条阶梯定价先排除。它与官方表可能重叠。
- 缺失缓存价格时，社区估价采用普通输入价格；未知模型、无法确认的别名保持“待定价”，用量仍计入。
- 自定义价格可在数据源窗口补充；单位是 USD / 百万 Token。
- 文件已有费用时优先采用文件费用，其余用当前 API 参考价估算。金额不是套餐实际扣款，也不是按历史价格复算的账单。部分多模态、区域折扣、批量计费和动态高峰价格不适用。
- 离线目录固定于 2026-09-22，随应用更新；不会在后台下载任意第三方价格。

## 安全和边界

Trae 同步默认关闭。开启后只读取本机 Trae Work CN 登录状态，凭证仅在内存使用，请求固定发往 HTTPS api.trae.cn，不跟随重定向。缺少登录、接口变化、页数不足或超过 2,000 个会话时显示错误并保留旧记录。其他 Trae 版本没有假称原生支持。

Cursor 当前已登录账号在最近一周、2026 年 8 月均显示无记录，CSV 导出不可用；格式兼容性用开源公开样例和合成记录验证，未取得真实有数据 CSV。

现有 Prism 皮肤和矢量图标改动从既有 TokenMini 工作树保留，本次数据接入未重新设计皮肤。
