PRIVACY · 2026-09-20

Privacy policy

TokenMini (formerly MacPulse) is a local-first, open-source macOS app. By default, there are no accounts, product analytics, advertising trackers, or automatic crash reports. Community rankings are currently offline: no ranking service is running, sign-in is unavailable, and nothing is synced. The sections below describe how rankings would work if the feature is restored.

Data that stays on your Mac by default

  • System metrics: CPU, memory, network, disk, battery, temperature, fan, and process information.
  • AI session statistics: local Claude Code and Codex JSONL logs are scanned read-only and aggregated on your Mac.
  • Skills: relevant directories are read or modified only when you actively use the management features.

Conversation content, prompts, responses, project names, paths, model breakdowns, session IDs, Claude/Codex credentials, API keys, system processes, file names, and device serial numbers are not uploaded to the rankings service.

Google sign-in and community rankings

All local features work without signing in, and public rankings can be browsed anonymously. Selecting “Sign in with Google and join” enrolls you in both weekly rankings (tokens and API-equivalent cost) and stores:

  • Your Google account identifier, email address, and display name. Your email is not shown publicly.
  • Your display-name preference. By default, all but the last character are masked.
  • Daily token totals and API-equivalent cost totals in the Shanghai time zone, the pricing-table version, and your TokenMini version.
  • Join, leave, and last-sync timestamps, plus necessary security audit records.

Sign-in tokens are stored only in macOS Keychain. Leaving the rankings stops syncing, deletes daily ranking totals and server refresh sessions, and clears local ranking credentials. Local monitoring is unaffected.

Other network requests

  • Enabling Claude quota checks requests Anthropic’s usage endpoint. A failure of this experimental feature does not affect other features.
  • Update checks read the official HTTPS appcast. Signed installers are downloaded from GitHub Releases.
  • Installing a Skill downloads content from the GitHub repository you specify.
  • Opening community rankings fetches the public list. The daily totals described above are uploaded only after you sign in and join.

Your controls

Notifications and Claude quota checks are off by default. You can leave the rankings at any time. Uninstalling TokenMini does not delete local Claude Code, Codex, or session files.

Report privacy and security concerns via GitHub Issues . For credentials or vulnerability details, follow the security policy to submit privately.
