# TokenMini 0.14.0 Public Beta

- 菜单栏图标与 Token 数值的左右留白更均衡；首次加载时使用紧凑占位。
- 多选筛选按钮整块区域都可点击，包含背景、箭头和留白。
- 保留 Prism 统一外观、完整中控台入口、多工具与多模型筛选及签名模型目录更新。
- 增加可选匿名产品统计基础，默认关闭。本次未配置正式接收服务，因此不上传产品统计，日活/周活尚未启用。
- 新增免费 GitHub 安装包下载报表，可导出 JSON/CSV，便于后期迁移。下载次数不代表用户数。
- 发布包移除编译机路径与调试记录，并加入安装包隐私检查，调试符号仅在本机私存。

Apple Silicon · macOS 14+ · Build 23。费用是 API 等价估算，不是订阅实际扣款。

Balances menu-bar spacing and makes the full multi-select button clickable. Optional analytics remains off and unconfigured in this build. Free GitHub installer-download reporting is available in the source tools.
