# TokenMini 0.15.3

- 新增 OpenAI GPT-6.2 系列（`gpt-6.2-sol`、`gpt-6.2-astra`）与 Anthropic Claude Fable 5.2（`claude-fable-5-2` / `claude-fable-5.2`）官方 API 标准定价，完整支持 >272K 长上下文整单倍率与 Fast 模式 2x 倍率。
- 升级 Codex 本地扫描器，新增支持新版 `thread_settings_applied` 事件中的模型、工作目录与服务档位兜底读取，避免部分会话在首个 `turn_context` 之前产生用量时丢失模型归属。
- 从 0.15.2 升级时，TokenMini 会重新核对仍在本机的 Codex 会话。继续使用旧会话时，每笔用量只计一次。已删除源文件的历史用量仍会保留。

Apple Silicon · macOS 14+ · Build 28

## English

- Add official API pricing for OpenAI GPT-6.2 (`gpt-6.2-sol`, `gpt-6.2-astra`) and Anthropic Claude Fable 5.2 (`claude-fable-5-2` / `claude-fable-5.2`), including >272K long-context full-request scaling and 2x Fast mode multipliers.
- Update the local Codex scanner to parse `thread_settings_applied` metadata (`model`, `cwd`, `service_tier`) as a fallback when `token_count` events precede `turn_context`.
- When upgrading from 0.15.2, TokenMini rereads available Codex sessions so continuing an existing session counts each usage record once. Usage history is preserved when the original log has been deleted.
