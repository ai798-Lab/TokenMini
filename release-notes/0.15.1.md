# TokenMini 0.15.1

- 修复 Codex 会话压缩后历史用量减少的问题。升级后会自动补读本机留存的压缩会话，把用量保存到独立账本。原文件和压缩文件并存时只记一次。
- 在「监控台 → 数据源」开启 DeepSeek 官方余额，可查看余额、查询时间和账号可用模型，每 5 分钟更新。项目或 Agent 接入调用日志后，TokenMini 每分钟读取 API 返回的实际 token 用量。
- 在 30 天趋势图中点选某一天，可同时查看当天的 token 总量和按 API 价格折算的费用。新增 GPT-6.1 Sol / Terra、Claude Sonnet / Haiku 5.5、Kimi K3.1 Pro 和 DeepSeek Flash 的价格与模型别名。

本次公开更新也包含过去 24 小时视图，以及简体中文、繁体中文、英语、日语、韩语和阿拉伯语界面。历史会话较多时，首次补读需要一些时间。

Apple Silicon · macOS 14+ · Build 26

## English

TokenMini now reads compressed and archived Codex sessions and keeps verified usage in a local ledger. Existing sessions are backfilled automatically. A session present in both formats is counted once.

Enable DeepSeek under Dashboard → Data Sources to see your official balance and available models. Projects and agents can send API response usage to the local log folder. Select a day in the 30-day chart to see its token count and estimated API cost. This release also updates model pricing and adds six interface languages and a rolling 24-hour view.
