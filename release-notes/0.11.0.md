# TokenMini 0.11.0

MacPulse is now **TokenMini** — a free, local-first AI usage monitor for Mac.

- New four-slice app icon, menu bar mark and consistent TokenMini naming across all themes, onboarding and app links.
- New website at https://tokenmini.cc, with a clearer focus on Claude Code / Codex usage, quota windows and Mac status.
- Existing preferences, local usage data, Keychain identity and update verification key are preserved. The legacy `macpulse` callback remains compatible.
- Includes the maintenance improvements previously delivered locally in 0.10.1: cancellable bounded scanning, per-item preview, explicit permission failures, file-identity checks before deletion, and verified process-exit feedback.
- Removes forced memory allocation as a “release memory” action; memory management helps you review and quit unused applications instead.
- Preserves selected GitHub branches when installing Skills.

## 安装与升级

打开 `TokenMini-0.11.0.dmg`，将 `TokenMini.app` 拖入“应用程序”。旧版原名 MacPulse；退出旧版后使用 TokenMini，设置继续沿用。若系统中保留了旧名称的副本，请避免同时运行。

本版需要 Apple Silicon 与 macOS 14 或更新版本。Token 购买服务未开放；官网与 App 当前均以监控台为主。费用为 API 等价估算，不代表订阅实际扣款。清理功能仍需你确认具体文件后才执行。
