# MacPulse 0.9.0 Public Beta

首个公开 Beta，面向 Apple Silicon 与 macOS 14 及以上版本。

## 主要功能

- 菜单栏系统状态与独立 Token 监控台
- Claude Code / Codex 本地会话用量与 API 等价成本估算
- Claude / Codex 额度窗口与可选提醒
- CPU、内存、网络、磁盘、电池、温度与风扇监控
- 安全缓存清理、进程结束与 Skills 管理
- 经典、HUD、LED 三套主题
- Sparkle 应用内检查更新

## 隐私变化

- 首次启动先展示数据使用说明
- Claude 额度默认关闭，主动开启后才访问钥匙串
- 通知默认关闭，主动开启后才申请系统权限
- 不上传会话正文，不包含统计、广告或崩溃遥测

## 已知边界

- 暂不支持 Intel Mac
- 不同 M 系列芯片可用的温度与风扇传感器可能不同
- Claude 额度依赖实验性接口，失效时不影响其他功能
